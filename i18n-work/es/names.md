# Spanish (es) — name and term renderings

## Fixed terms
- The Mushling Oracle → El Oráculo Mushling
- Mushling / Mushlings → Mushling / Mushlings (el Mushling, los Mushlings; female characters: una Mushling, la Mushling)
- Sage (guide) → Sage (kept as a name; avoid gendered adjectives for the guide where possible)
- deck → baraja
- spread → tirada
- reading → lectura
- card → carta
- story → cuento (Story Time → Hora del cuento)
- journal → diario
- synthesis → síntesis
- cap (mushroom cap) → sombrero
- dear human / dear human reader → querido ser humano (gender-neutral in meaning)
- reader address → tú

word is a plant/thing the story touches (Fern, Clover, Mossy, Berry, Willow, Ash…). This
