# Ukrainian (uk) — name renderings

## Recurring terms
- Mushling / Mushlings → **грибеня / грибенята** (neuter, like каченя/кошеня — "-ling" = "-еня"; gen. pl. грибенят). Lowercase in running text, like any creature type.
- Sage (the guide, = the Mushling on card 4) → **Сейдж** (declined as masculine: Сейджа, Сейджеві, із Сейджем)
- The Mushling Oracle → **Оракул грибенят**
- card → карта; spread / reading → розклад; synthesis → підсумок; story → казка; journal → щоденник
- Reader is addressed as ти, always gender-free (no past tense or gendered adjectives for "you"; "тобі випала карта", "наодинці", impersonal "вдалося/доводилося").

## Translated names (the story plays on the meaning)
- Mossy (5) → **Моховичок** (m; моховик is a moss-loving mushroom; he rests on мох)
- Elder Moss (19, 49) → **Старійшина Мох** (m)
- Clover (9, 17, 24, f) → **Конюшинка** (tends a four-leaf конюшина)
- Spark (8, the firefly, m) → **Вогник** (echoed by "вогник надії")
