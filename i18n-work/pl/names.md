# Polish (pl) — name renderings

## Fixed terms
- The Mushling Oracle → **Wyrocznia Mushlingów**
- Mushling (creature, capitalized as in English, masc. animate):
  sg. Mushling, Mushlinga, Mushlingowi, Mushlingiem, o Mushlingu;
  pl. Mushlingi, Mushlingów, Mushlingom, Mushlingami, o Mushlingach. Adj.: mushlingowy.
  Feminine form for a female Mushling in apposition: **Mushlinka** (Mushlinki, Mushlince, Mushlinką) — e.g. „Mushlinka Willow”, „Mushlinka imieniem Clover”. Plural for groups stays Mushlingi (non-virile verbs: Mushlingi przychodziły).
- Sage (guide, also card 4) → **Sage** (masc. declension with apostrophe: Sage'a, Sage'owi, Sage'em, o Sage'u). Guide's own verbs kept gender-free where possible.
- reading → odczyt; spread → rozkład; deck → talia; card → karta; message → przesłanie; meaning → znaczenie; story → opowieść; journal → dziennik
- "dear reader" → drogi czytelniku; "dear human" → drogi człowieku
- Reader addressed as **ty**; past-tense/adjective forms for the reader avoided where possible (gender-neutral phrasing).
