# Korean (ko) name renderings — The Mushling Oracle

Decision: every personal name is rendered phonetically in Hangul (no native-word substitutions),
so the cast reads as one consistent family of names. Many already carry their meaning for Korean
readers through familiar loanwords (클로버, 베리, 세이지, 오팔, 코랄, 헤이즐, 피그).

## Fixed terms
- The Mushling Oracle → 머쉬링 오라클
- Mushling / Mushlings → 머쉬링 / 머쉬링들
- Sage (the guide, also the Mushling on card 4) → 세이지
- reading → 리딩 · spread → 스프레드 · journal → 일기장 · card → 카드
- Reader address: soft 해요체; "dear reader" → "책장을 넘기는 당신", "이 이야기를 듣는 당신" etc.;
  "dear human" → "사람 친구인 당신"; "you" → 당신 only where needed, usually omitted.
