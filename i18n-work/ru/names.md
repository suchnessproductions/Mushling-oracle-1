# Russian (ru) — name renderings

## Recurring terms
- Mushling / Mushlings → грибыш (m.), грибышка (f., when the character is female), грибыши (pl.), gen. pl. грибышей. Lowercase in running text, like «хоббит».
- The Mushling Oracle → Оракул грибышей
- Sage (the guide, and the Mushling on card 4) → Шалфей (m.; declines: Шалфея, Шалфею, Шалфеем, о Шалфее). The guide uses "they" in English; Russian grammar follows the masculine noun.
- spread → расклад; reading → расклад; synthesis → толкование; journal → дневник; story → сказка
- Today's Mushling → Грибыш дня
- "dear reader / dear human" → «дорогой мой человек», «дорогой читатель»

## Reader address
- ты throughout. Russian past tense, short adjectives and «мог бы» are gendered, so the reader is never given a gendered form: present tense, impersonal and passive constructions instead («тебе пришлось», «если тебе выпала эта карта», «всё уже сделано»).
