# zh name renderings (decide once, use everywhere)

## Fixed terms
- Mushling / Mushlings → 小菇灵 (measure word 个; plural same: 小菇灵们)
- Sage (guide + card 4) → 赛吉
- The Mushling Oracle (app) → 小菇灵神谕卡
- Mushling AI Guide → 小菇灵 AI 向导
- card / deck / spread / reading → 牌 / 牌组（整副牌）/ 牌阵 / 解读
- synthesis → 综合解读
- Message / Meaning / Story tabs → 寄语 / 释义 / 故事
- Gallery → 图鉴 · Journal → 日记
- "dear reader" → 亲爱的读者 · "dear human" → 亲爱的人类朋友 / 亲爱的人类

## Policy for personal names
Phonetic Chinese by default (pleasant, name-like characters). A native nature name only
where the story or title plays on the word.
